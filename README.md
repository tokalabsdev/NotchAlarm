# NotchAlarm

**Повітряні тривоги України — в «чубчику» вашого Mac і вгорі екрана Windows.**
Тип загрози, таймер тривоги, карта, історія, кілька територій, сповіщення зі звуком.

🌐 Сайт: **https://notchalarm.pages.dev**

## Завантажити

| Система | Файл |
|---|---|
| macOS 14+ (MacBook з «чубчиком» і без) | [NotchAlarm для Mac](https://notchalarm.pages.dev/download/mac) |
| Windows 10 / 11 (64-біт) | [NotchAlarm для Windows](https://notchalarm.pages.dev/download/windows) |
| iPhone | Незабаром |

Усі версії — на сторінці [Releases](https://github.com/tokalabsdev/NotchAlarm/releases).
Контрольні суми — у файлі `SHA256SUMS.txt` кожного випуску. Програми оновлюються самі.

> ⚠️ NotchAlarm доповнює, а не замінює офіційне сповіщення. Завжди користуйтесь офіційними джерелами сповіщення про загрозу ukrainealarm.com!

Дані — ukrainealarm.com. NotchAlarm безкоштовний для всіх.
Підтримати розробку: [Банка monobank](https://send.monobank.ua/jar/5rrnWmNDXq)

---

**English.** NotchAlarm shows Ukrainian air-raid alerts in your MacBook's notch (and at the top of the screen on Windows): threat type, timer, map, history, notifications. Download from [Releases](https://github.com/tokalabsdev/NotchAlarm/releases) or the [website](https://notchalarm.pages.dev).
